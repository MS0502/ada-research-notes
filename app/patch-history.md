# Ada 앱 패치 기록

실사용에서 어떤 불편이 있었는지, 무엇을 바꿨는지, 누구의 제안과 검증으로 들어갔는지를 원래 작업 보고서에서 대조했습니다. 개발 경로는 [채팅 실행 기록과 우측 작업 보기](../cases/ada-app-execution-view.md)에서 실제 화면으로 볼 수 있습니다.

## 사용자 요청으로 시작한 변경

| 변경 | 왜 필요했나 | 어떻게 고쳤나 | 확인과 남은 범위 |
| --- | --- | --- | --- |
| 같은 채팅에서 이어 쓰기 | 이전 요청을 다시 물었을 때 Ada가 작업 메모만 이어받아 대화를 잊음 | 앱에서 최근 대화 일부를 같은 채팅의 후속 요청에 붙이고, 다른 작업 중 요청은 대기열로 보냄. Claude가 이어받아 구현·검증 | README 첫 줄 요청을 기억했으며, 대기한 요청이 앞 작업 뒤 자동으로 실행됨. 길이는 당시 최대 8,000자 |
| 채팅의 ‘지금 하는 일’ | 영문 독백이 대화 줄을 차지해 진행을 읽기 어려움 | 기존 도구 이벤트에서 `README.md 읽기` 같은 한국어 상태를 만들고 원문은 접은 상태로 보관. Claude가 구현·검증 | 테스트 채팅에서 보이는 영문 독백 0건. [실제 화면](../cases/ada-app-execution-view.md) |
| 채팅 메뉴 클릭과 제목 | `⋯`를 여러 번 눌러야 했고 제목이 잘렸다는 사용자 신고 | 누를 때 바뀌는 애니메이션이 기존 위치 변환을 덮지 않도록 수정. 제목 대체값과 헤더 줄바꿈도 보강. Claude가 위치 이동을 대조 | 한 재현에서 메뉴의 클릭 중 이동이 14px → 0px. 후속 실사용에서 이벤트 갱신으로 메뉴가 다시 닫히는 두 번째 원인도 따로 발견 |
| 긴 코드와 답변 읽기 | 사용자 요청으로 긴 코드의 복사·접기, 긴 답변의 맨 위 이동을 추가 | 코드 헤더에 언어·줄 수·복사를 모으고 긴 코드에 접기와 스크롤을 제공. Claude가 여러 화면 폭에서 검증 | 검증 예제의 접힘 높이 360px, 펼침 839px. UI 동작을 확인했으며 일반 문서의 읽기 속도는 재지 않음 |

## 외부 에이전트의 조사·제안으로 시작한 변경

| 변경 | 원인과 제안 출처 | 적용과 실제 확인 |
| --- | --- | --- |
| 앱의 사용자 기억 설정 테스트 | GPT가 기존 테스트가 공용 설정을 읽는데 앱은 앱 전용 설정을 읽어서 실패한다고 진단. Claude가 재현하고 수정에 반영 | 앱 전용 설정에서 기억 기능을 확인하고 공용·벤치마크 설정에서는 꺼져 있는지 함께 검사. 해당 변경 뒤 묶음 회귀 2,222 통과·55 제외·하위 검사 5 통과 |
| 셸 실행마다 터미널 창이 뜨는 문제 | Claude의 실사용·재현 기록에서 숨겨 둔 상위 워커와 별도로 셸 자식이 새 콘솔을 만든다는 점 확인. 최초 신고자는 이 기록에서 미확인 | 기본 자식 실행에 창 없음 옵션 적용. 테스트 채팅의 새 PowerShell 창 5개 → 0개, 명령 결과 정상 확인 |
| 복셀 그래픽 품질 절차 | Ada가 실사용 과제에서 이전 성찰 스킬을 찾아 읽고 텍스처·하늘·물 표현을 개선. 외부 리뷰에서 구름 작업 지연과 회색 잔디 아이콘을 발견 | 리뷰를 바탕으로 관련 스킬 찾기, 큰 화면부터 검수, 월드와 아이콘의 대응 확인을 절차에 보강. 같은 품질 지표의 재실험은 미확인 |

앱 기록에는 사용자 의견과 외부 리뷰가 함께 들어간 변경이 있습니다. 위 표는 확인되는 최초 발단과 후속 검증을 적었습니다. 단체 승인이나 모바일 기기 수준의 실사용까지 확인하지 못한 항목은 개별 테스트 범위로 읽으면 됩니다.
