# 외부 검증기를 실행하기 전에 확인한 것

초기 Ada 저장소 `local-agent`에는 외부 머신에서 벤치마크를 실행할 준비가 됐는지 확인하는 수동 GitHub Actions 워크플로가 있었습니다. 이 글은 기존 저장소의 README 두 편에서 확인한 설계를 옮긴 기록입니다.

사전 점검은 운영체제와 CPU 아키텍처, CPU·RAM·디스크, Docker 클라이언트와 데몬의 응답을 기록합니다. 간단한 Docker `hello-world` 실행으로 컨테이너가 뜨는지도 확인합니다. 디스크 120 GiB는 점검 기준으로 설정돼 있었습니다. 실제 과제 이미지가 들어갈지는 이미지 크기와 필요한 임시 공간을 확인해야 알 수 있습니다.

벤치마크를 실행하려면 과제 이미지의 식별자와 다이제스트, 호환되는 검증 코드 버전, 실행 명령을 고정해야 합니다. 이 입력이 준비되기 전에는 검증 스크립트가 실행을 중단하도록 설계돼 있었습니다. 사전 점검에서 벤치마크 이미지를 받거나 과제를 채점하는 단계는 수행하지 않습니다.

이 문서로 확인할 수 있는 범위는 저장소에 기록된 절차까지입니다. 실제 점검 통과 여부나 과제 성적을 확인할 실행 결과는 이 기록에 포함돼 있지 않습니다.
